# POS Card Installment

Agrega selección de tarjeta y plan de cuotas al pago del Punto de Venta. El recargo
financiero y el ajuste de redondeo se registran en una sola línea, y el total se
redondea hacia arriba solo para los importes pagados con tarjeta/cuotas.

## Configuración

En la configuración del Punto de Venta seleccione un producto para el recargo financiero.
El mismo producto recibe el ajuste de redondeo, con su mismo tratamiento fiscal y contable.
Las ventas pagadas únicamente con efectivo u otros métodos sin cuotas no se redondean.
